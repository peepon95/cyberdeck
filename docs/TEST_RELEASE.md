# Cyberdeck 2.0 v0.1.0-test

This is the first cleaned package for **independent friend testing**. It is not
the final public-workshop release yet.

## Tested in software

- Eight app manifests and Python entry points
- Full and selective installation flows
- Timestamped recovery backup flow
- Dynamic menu discovery
- Ten Chinese Lingo asset, progress and stroke-grading tests
- Release archive contents and SHA-256 checksum

## Still needs physical testing

- Fresh Raspberry Pi OS microSD setup
- 3.5-inch 480×320 GPIO display and `/dev/fb1`
- XPT2046/ADS7846 touch calibration and stylus input
- Wired keyboard navigation and Journal input
- Every app's return-to-menu behaviour
- Reinstallation recovery and safe shutdown

Please follow [`docs/FRIEND_TEST.md`](https://github.com/peepon95/cyberdeck/blob/main/docs/FRIEND_TEST.md)
and report the exact step, terminal output and a screen photo for any problem.

Download `cyberdeck-workshop.zip`, verify it against `SHA256SUMS`, extract it,
and begin with the repository README.
