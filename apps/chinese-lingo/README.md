# Chinese Lingo

An offline, level-based simplified Chinese stroke trainer. The first course
teaches 20 characters with watch and guided-practice screens.

Beginner customization ideas:

- Change the XP awarded for a correct character.
- Change the course colours or completion message.
- Add another four-character level using properly licensed stroke data.

The bundled stroke and dictionary subset comes from Make Me a Hanzi. Keep the
files in `licenses/` when redistributing this app.
